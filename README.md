## Σύνοψη
**Για χρήση σε μεγάλη οθόνη** / Υπολογιστή ή ταμπλέτα

Το Network Simulation Tool είναι ένα διαδραστικό, οπτικό εργαλείο προσομοίωσης δικτύων υπολογιστών, σχεδιασμένο ειδικά για εκπαιδευτικούς σκοπούς. Επιτρέπει στους μαθητές και εκπαιδευτικούς να κατασκευάσουν εικονικά δίκτυα, να συνδέσουν συσκευές και να κατανοήσουν τις βασικές αρχες των Δικτύων Υπολογιστών.

## Χαρακτηριστικά
- Διαδραστική προσομοίωση με drag & drop συσκευών και μετακίνηση της προβολής με σύρσιμο στο κενό
- Πολλών τύπων συσκευές: Routers, Switches, Firewall, Υπολογιστές, Servers, DNS, Cloud, Εκτυπωτές
- Δρομολόγηση σύμφωνα με τη θεωρία:
  - τα switches προωθούν μέσα στο ίδιο δίκτυο, οι routers μεταξύ δικτύων
  - ο host στέλνει απευθείας μόνο σε διεύθυνση του δικτύου του, αλλιώς στο gateway, που πρέπει να ανήκει στο δίκτυό του
  - ο router επιλέγει τη πιο συγκεκριμένη διαδρομή (longest prefix match)
  - NAT όταν ιδιωτική διεύθυνση βγαίνει από WAN με δημόσια IP
  - το ping πετυχαίνει μόνο αν επιστρέψει και η απάντηση
- Πίνακας δρομολόγησης στο πάνελ του router (στατικές διαδρομές) και αυτόματη δημιουργία διαδρομών
- Firewall (transparent, stateful) με θύρες inside/outside, πολιτική και κανόνες ανά πρωτόκολλο, θύρα, πηγή και προορισμό
- Δοκιμές Ping, Διαδρομής, DNS (UDP/53) και υπηρεσιών TCP/UDP (π.χ. tcp/80), με εξήγηση της αιτίας όταν αποτυγχάνουν
- Ανίχνευση διπλότυπων IP στο ίδιο δίκτυο
- Οπτικοποίηση της διαδρομής των πακέτων και προσομοίωση κυκλοφορίας
- Αποθήκευση και φόρτωση workspace (JSON) και έτοιμα μοντέλα
- Πραγματικού χρόνου κονσόλα και ενσωματωμένη βοήθεια (F1)
- Πλήρης υποστήριξη Ελληνικής γλώσσας

## Γρήγορη Εκκίνηση
Η εφαρμογή χρησιμοποιεί JavaScript modules, οπότε χρειάζεται τοπικός web server (το άνοιγμα του `index.html` απευθείας από τον δίσκο δεν λειτουργεί).

```bash
git clone https://github.com/gethanos/Diktio.git
cd Diktio
python3 -m http.server 8000
```

Ανοίξτε το http://localhost:8000 στον browser. Δεν χρειάζεται εγκατάσταση ή build.

## Έτοιμα Μοντέλα
Από το κουμπί **Μοντέλα**:
- **Απλό LAN**: switch με υπολογιστές, server, DNS και εκτυπωτή σε ένα δίκτυο
- **2 Υποδίκτυα → 1 Switch**: δύο υποδίκτυα στο ίδιο switch χωρίς router
- **Πλήρες LAN → WAN**: δύο LAN, router και Internet (NAT)
- **Δύο γραφεία, στατική δρομολόγηση**: δύο routers με σύνδεση 10.0.0.0/30 και στατικές διαδρομές
- **Firewall που προστατεύει server**: Web και DNS server πίσω από firewall που επιτρέπει μόνο HTTP και DNS

## Τύποι Συσκευών
- **Router**: Δρομολογητής με WAN, LAN και LAN2 (WAN: N/A, LAN: 192.168.1.1, LAN2: 192.168.2.1) και πίνακα δρομολόγησης
- **Switch**: Μεταγωγέας (Layer 2) (Χωρίς IP ή managed)
- **Firewall**: Transparent firewall με θύρες inside/outside, κανόνες και IP διαχείρισης
- **Computer**: Τυπικός υπολογιστής (192.168.1.x)
- **Server**: Δικτυακός εξυπηρετητής (192.168.1.x)
- **DNS Server**: DNS Εξυπηρετητής (192.168.1.53)
- **Cloud**: WAN/Internet προσομοίωση (8.8.8.8)
- **Printer**: Δικτυακός εκτυπωτής (192.168.1.x)

## Ανάπτυξη και Tests
Τα tests χρειάζονται [Node.js](https://nodejs.org/) 22 ή νεότερο. Το `jsdom` εγκαθίσταται μόνο για τα tests και δεν χρησιμοποιείται από την εφαρμογή.

```bash
npm install
npm test                  # unit tests: διευθύνσεις, δρομολόγηση, NAT, firewall
npm run test:scenarios    # σενάρια με τον πραγματικό κώδικα της εφαρμογής και τα μοντέλα
npm run test:ui           # κλικ σε όλη την εφαρμογή (jsdom)
npm run test:smoke        # εκκίνηση της εφαρμογής
```

Δομή κώδικα (`assets/js/`):
- `network-core.js`: διευθύνσεις IPv4, μάσκες, υπολογισμοί δικτύου
- `routing.js`: μοντέλο προώθησης (switching, ARP, διαδρομές, NAT, ping)
- `firewall.js`: κανόνες και απόφαση του firewall
- `devices.js`, `connections.js`, `simulation.js`, `ui.js`, `main.js`: συσκευές, συνδέσεις, δοκιμές, περιβάλλον χρήσης
- `workspace-manager.js`: αποθήκευση και φόρτωση workspace
