-  Μαθαίνονται μόνο οι γείτονες (ένα βήμα). Για αλυσίδες τριών ή περισσότερων routers χρειάζονται στατικές διαδρομές.

## 🌐 ΠΡΟΚΑΘΟΡΙΣΜΕΝΑ ΜΟΝΤΕΛΑ JSON

### 📂 ΔΙΑΘΕΣΙΜΑ ΜΟΝΤΕΛΑ  

-  Πατήστε Load Model (📁) για να ανοίξει το παράθυρο επιλογής μοντέλων.  

-  Διαθέσιμα μοντέλα:  
  - Απλό LAN: Ένα switch με υπολογιστή, server, DNS και εκτυπωτή στο ίδιο δίκτυο, χωρίς router.  
  - 2 Υποδίκτυα σε 1 Switch: Δύο υποδίκτυα στο ίδιο switch χωρίς router: επικοινωνούν μόνο οι συσκευές του ίδιου υποδικτύου.  
  - LAN με router: Router, switch, υπολογιστής, server και DNS server σε ένα LAN.  
  - Απλό WAN Δίκτυο: Υπολογιστής, switch και router με σύνδεση στο Internet: το μικρότερο παράδειγμα NAT.  
  - LAN με router και Internet: Το LAN με router συνδεδεμένο στο Internet μέσω WAN (NAT).  
  - Γραφείο με 2 LAN και Internet: Router με δύο LAN υποδίκτυα και σύνδεση στο Internet.  
  - Δύο γραφεία, στατική δρομολόγηση: Δύο routers σε σύνδεση 10.0.0.0/30 με στατικές διαδρομές προς τις δύο κατευθύνσεις.  
  - Firewall που προστατεύει server: Web και DNS server πίσω από firewall που επιτρέπει μόνο HTTP (tcp/80) και DNS (udp/53).  

-  Κατά τη φόρτωση μοντέλου φορτώνονται αυτόματα συσκευές, συνδέσεις και DNS records σαν έτοιμο workspace.

## ⚙️ ΡΥΘΜΙΣΕΙΣ ΣΥΣΚΕΥΩΝ (ΓΕΝΙΚΑ)

-  Κάθε συσκευή έχει ιδιότητες: IP, Subnet Mask, Gateway, DNS Server, Domain Name (όπου υποστηρίζεται) και Status.  
-  Όλες οι αλλαγές περνούν από έλεγχο εγκυρότητας (0–255 για IP octets, επιτρεπόμενες μάσκες κ.λπ.). Σε μη έγκυρη τιμή εμφανίζεται μήνυμα σφάλματος και η ρύθμιση δεν εφαρμόζεται.  

-  Βασικά πεδία:  
  - IP Address: μορφή x.x.x.x με κάθε octet 0–255 (π.χ. 192.168.1.10).  
  - Subnet Mask: τυπικές μάσκες όπως 255.255.255.0, 255.255.0.0, 255.0.0.0 κ.ά.  
  - Gateway: συνήθως η IP του router στο ίδιο δίκτυο (ή 0.0.0.0 αν δεν υπάρχει).  
  - DNS Server: IP DNS server (εσωτερικού ή εξωτερικού, π.χ. 192.168.1.53 ή 8.8.8.8).  
  - Domain Name: ονομασία τύπου host.local που καταχωρείται και στο DNS.

## 🧭 ROUTER – ΠΟΛΛΑΠΛΕΣ ΔΙΕΠΑΦΕΣ

Ο router διαθέτει τουλάχιστον τρεις λογικές διεπαφές: WAN, LAN και LAN2.

**Προεπιλεγμένες ρυθμίσεις όταν προστίθεται νέος router:**  

-  WAN  
  - IP: N/A  
  - Subnet: 255.255.255.0  
  - Gateway: 0.0.0.0  
  - DNS: 8.8.8.8  

-  LAN (192.168.1.0/24)  
  - IP: 192.168.1.1  
  - Subnet: 255.255.255.0  
  - Gateway: 0.0.0.0  
  - DNS: 192.168.1.1  

-  LAN2 (192.168.2.0/24)  
  - IP: 192.168.2.1  
  - Subnet: 255.255.255.0  
  - Gateway: 0.0.0.0  
  - DNS: 192.168.2.1  
  - Κατάσταση: enabled = true (μπορεί να απενεργοποιηθεί από checkbox).  

Στο πάνελ router μπορείτε να ρυθμίσετε ξεχωριστά IP, Subnet, Gateway και DNS για WAN, LAN και LAN2, καθώς και να ενεργοποιήσετε ή να απενεργοποιήσετε τη LAN2. Οι διεπαφές πρέπει να ανήκουν σε διαφορετικά δίκτυα.  

Όταν συνδέετε καλώδιο σε router, επιλέγετε τη διεπαφή (WAN, LAN ή LAN2). Ένα switch συνδεδεμένο σε μία διεπαφή ανήκει μόνο στο δίκτυο αυτής της διεπαφής: ο router δεν γεφυρώνει τις διεπαφές του.  

### 📋 ΠΙΝΑΚΑΣ ΔΡΟΜΟΛΟΓΗΣΗΣ  
-  Στο πάνελ router εμφανίζονται οι διαδρομές (δίκτυο/πρόθεμα, επόμενο βήμα, διεπαφή, metric).  
-  Προσθήκη στατικής διαδρομής: δίκτυο προορισμού, μάσκα, επόμενο βήμα (gateway) και διεπαφή εξόδου. Το gateway πρέπει να ανήκει στο δίκτυο της διεπαφής εξόδου.  
-  Επιλογή διαδρομής: προτιμάται η πιο συγκεκριμένη (μεγαλύτερο πρόθεμα), μετά το μικρότερο metric. Αν καμία δεν ταιριάζει, χρησιμοποιείται το WAN gateway (default route).  

### 🔁 NAT  
-  Πακέτο με ιδιωτική διεύθυνση πηγής (10.x, 172.16-31.x, 192.168.x) που βγαίνει από WAN με δημόσια IP παίρνει ως πηγή τη WAN IP του router. Έτσι οι συσκευές του LAN φτάνουν στο Internet, αλλά το Internet δεν μπορεί να ξεκινήσει σύνδεση προς αυτές.  
-  Σε WAN με ιδιωτική IP (π.χ. σύνδεση δύο γραφείων) δεν γίνεται NAT και χρειάζονται διαδρομές και προς τις δύο κατευθύνσεις.

## 🔀 SWITCH

Ο switch υποστηρίζει unmanaged και managed λειτουργία.  

-  Unmanaged switch (προεπιλογή):  
  - IP: N/A  
  - Subnet: 255.255.255.0  
  - Gateway: 0.0.0.0  
  - DNS: κενό  
  - Χρήση: απλό Layer 2, χωρίς IP διαχείρισης.  

-  Managed switch:  
  - Αν δοθεί IP στο πάνελ, μπορείτε να ρυθμίσετε και Subnet, Gateway, DNS όπως σε κανονική συσκευή.  
  - Η IP είναι μόνο για διαχείριση. Το switch δεν παίρνει IP αυτόματα όταν συνδέεται σε router.  

***

## 🛡️ FIREWALL

Το firewall λειτουργεί σε transparent (bridge) λειτουργία: μπαίνει ανάμεσα σε δύο τμήματα του ίδιου δικτύου και ελέγχει κάθε πακέτο που περνά.  

-  Θύρες: inside (το προστατευόμενο δίκτυο) και outside (το εξωτερικό). Κατά τη σύνδεση επιλέγετε θύρα. Μέγιστο δύο καλώδια.  
-  Η IP του firewall είναι μόνο για διαχείριση (μπορεί να γίνει ping σε αυτήν).  
-  Κατεύθυνση: inside → outside είναι εξερχόμενη, outside → inside εισερχόμενη.  
-  Προεπιλεγμένη πολιτική: εξερχόμενη επιτρέπεται, εισερχόμενη απαγορεύεται. Αλλάζει από το πάνελ.  
-  Κανόνες: ενέργεια (επιτρέπεται/απαγορεύεται), κατεύθυνση, πρωτόκολλο (ICMP, TCP, UDP ή όλα), θύρα (μόνο TCP/UDP), πηγή και προορισμός (any, IP ή δίκτυο σε μορφή CIDR, π.χ. 192.168.2.0/24).  
-  Οι κανόνες ελέγχονται με τη σειρά και ισχύει ο πρώτος που ταιριάζει. Με το ↑ αλλάζει η σειρά. Αν κανένας δεν ταιριάζει, ισχύει η πολιτική.  
-  Stateful: η απάντηση σε κίνηση που επιτράπηκε περνά πάντα (π.χ. ο server απαντά στο ping που ξεκίνησε από μέσα).  
-  Όταν ένα πακέτο απορρίπτεται, η κονσόλα δείχνει ποιο firewall και ποιος κανόνας ή ποια πολιτική το απέρριψε.

## 💻 STANDARD ΣΥΣΚΕΥΕΣ (PC, SERVER, PRINTER)

Standard συσκευές μοιράζονται κοινή λογική IP configuration.  

-  Χωρίς router στο workspace:  
  - IP: ελεύθερη διεύθυνση στο 192.168.1.0/24  
  - Subnet: 255.255.255.0  
  - Gateway: 0.0.0.0  
  - DNS: 8.8.8.8  

-  Με router (π.χ. 192.168.1.1):  
  - IP: ελεύθερη διεύθυνση στο LAN του router, με τη μάσκα του LAN (ποτέ η διεύθυνση δικτύου, η broadcast ή IP άλλης συσκευής).  
  - Gateway: 192.168.1.1  
  - DNS: συνήθως 192.168.1.1 (ή άλλη τιμή αν οριστεί).  

Στο πάνελ μπορείτε να αλλάξετε IP, Subnet, Gateway, DNS και Domain Name. Κενό πεδίο Gateway ή DNS σημαίνει «χωρίς gateway» ή «χωρίς DNS». Δεν επιτρέπεται gateway εκτός δικτύου της συσκευής.  
Όταν ορίσετε Domain Name και υπάρχει έγκυρη IP, δημιουργείται αυτόματα DNS A record.

## 🧱 DNS SERVER

Ο DNS server είναι ειδική συσκευή τύπου dns με δικό της σύνολο εγγραφών.

**Προεπιλεγμένες ρυθμίσεις DNS server:**  

-  IP: 192.168.1.53  
-  Subnet: 255.255.255.0  
-  Gateway: 192.168.1.1  
-  DNS: 192.168.1.53 (self)  

Στο πάνελ DNS μπορείτε:  
-  Να προσθέσετε νέες εγγραφές (host → IP).  
-  Να διαγράψετε υπάρχουσες εγγραφές.  
-  Να δείτε ταξινομημένη λίστα εγγραφών (Local, External, Custom).  

Ο DNS Manager διατηρεί έναν global πίνακα με:  
-  Εξωτερικά ονόματα (π.χ. google.com, github.com).  
-  Τοπικά ονόματα (router.local, dns.local, printer.local κ.λπ.).  
-  Domain names που έχετε ορίσει στις συσκευές.

## 🌐 DNS RESOLUTION – ΛΟΓΙΚΗ

Όταν μια συσκευή κάνει DNS query (αυτόματα ή μέσω Manual DNS):  

1. Ελέγχεται η τοπική DNS cache της συσκευής.  
2. Αν υπάρχει ρυθμισμένος DNS server (στο πεδίο DNS), γίνεται προσπάθεια να χρησιμοποιηθεί αυτός ο DNS server. Το query είναι πακέτο UDP/53: ακολουθεί δρομολόγηση, NAT και κανόνες firewall όπως κάθε πακέτο.  
3. Αν δεν βρεθεί DNS συσκευή, γίνεται αναζήτηση στα global DNS records.  
4. Αν υπάρχει συσκευή με domainName ίδιο με το ζητούμενο, επιστρέφεται η IP της.  
5. Σε επιτυχία, η IP αποθηκεύεται στην cache και εμφανίζεται μήνυμα RESPONSE στην κονσόλα με οπτική κίνηση πακέτου DNS.  
6. Σε αποτυχία, εμφανίζεται QUERY failed με αντίστοιχο μήνυμα.

## 🔧 ΕΡΓΑΛΕΙΑ ΔΙΚΤΥΟΥ

### 🚀 PING  
1. Επιλέξτε συσκευή στο workspace.  
2. Πατήστε Ping.  
3. Επιλέξτε προορισμό: αριθμό από τη λίστα (περιλαμβάνει routers και firewalls) ή IP. Με IP γίνεται ping στη συγκεκριμένη διεύθυνση, π.χ. στη LAN2 ενός router.  
4. Η κονσόλα εμφανίζει το αποτέλεσμα και τη διαδρομή.  

Το ping πετυχαίνει μόνο αν φτάσουν και το αίτημα και η απάντηση. Σε αποτυχία εμφανίζεται η αιτία, π.χ.:  
-  δεν υπάρχει διαδρομή (λείπει gateway ή στατική διαδρομή),  
-  το επόμενο βήμα δεν απαντά σε ARP (λάθος καλώδιο, μάσκα ή gateway εκτός δικτύου),  
-  διπλότυπη IP στο ίδιο δίκτυο,  
-  βρόχος δρομολόγησης (TTL expired),  
-  μπλοκαρίστηκε από firewall,  
-  «δεν επιστρέφει απάντηση»: το αίτημα έφτασε αλλά ο προορισμός δεν έχει διαδρομή επιστροφής.  

### 🔌 ΥΠΗΡΕΣΙΑ (TCP/UDP)  
1. Από το πάνελ συσκευής πατήστε Υπηρεσία (ή Δοκιμές → Δοκιμή Υπηρεσίας).  
2. Δώστε πρωτόκολλο/θύρα, π.χ. tcp/80, tcp/443, udp/53.  
3. Επιλέξτε προορισμό. Η διαδρομή είναι ίδια με του ping, αλλά τα firewalls εφαρμόζουν τους κανόνες για τη συγκεκριμένη υπηρεσία.  

### 🛣️ ROUTE (Διαδρομή)  
1. Πατήστε Route.  
2. Επιλέξτε συσκευή πηγή.  
3. Επιλέξτε συσκευή προορισμό.  
4. Εμφανίζεται η διαδρομή με όλα τα ενδιάμεσα hops (router, switches) με οπτικοποίηση στο workspace.  

### ✋ MANUAL DNS  
1. Πατήστε Manual DNS.  
2. Επιλέξτε συσκευή-πηγή.  
3. Επιλέξτε DNS server.  
4. Εισάγετε domain name.  
5. Το αποτέλεσμα (επιτυχία ή αποτυχία, IP προορισμού, πηγή εγγραφής) εμφανίζεται στην κονσόλα με animation DNS query/response.  

### ▶️ SIMULATION  
-  Πατήστε Simulate για να ξεκινήσει ροή τυχαίων πακέτων στο δίκτυο.  
-  Τα πακέτα εμφανίζονται οπτικά στις συνδέσεις και ενημερώνονται τα counters.  
-  Πατήστε ξανά Simulate για παύση.

## ⚠️ TROUBLESHOOTING

### 🔌 Χωρίς επικοινωνία / πρόβλημα συνδέσεων  
-  Διαβάστε την αιτία αποτυχίας στην κονσόλα: αναφέρει και τη συσκευή όπου σταμάτησε το πακέτο.  
-  Ελέγξτε IP, subnet και gateway. Το gateway πρέπει να ανήκει στο δίκτυο της συσκευής.  
-  Ελέγξτε ότι ο router έχει διαδρομή προς τον προορισμό και ο προορισμός διαδρομή επιστροφής.  
-  Ελέγξτε τους κανόνες των firewalls στη διαδρομή.  

### 🌐 Προβλήματα με DNS  
-  Ελέγξτε ότι η συσκευή έχει σωστό DNS server (π.χ. 192.168.1.53 ή 192.168.1.1).  
-  Χρησιμοποιήστε Manual DNS για δοκιμή επίλυσης συγκεκριμένου domain.  
-  Ελέγξτε αν το domain υπάρχει στα DNS records ή ως domainName κάποιας συσκευής.  

### ▶️ Η προσομοίωση δεν ξεκινά  
-  Ελέγξτε ότι υπάρχουν τουλάχιστον δύο συσκευές συνδεδεμένες.  
-  Βεβαιωθείτε ότι οι συσκευές είναι online και έχουν έγκυρες IP ρυθμίσεις.

-  Πατήστε F1 ή το κουμπί Help (❓) για να ανοίξει ο οδηγός μέσα στην κονσόλα σε fullscreen mode.
